# Recording preflight

- [ ] Check the saved index and source files exist; use `reset-demo.sh` only if a fresh demo index is needed.
- [ ] Run `bash final_submission/demo/launch-demo.sh` from the repository root.
- [ ] Confirm the status badge reads **CPU CLIP backend**, indexing is idle, and three videos are listed.
- [ ] Search exactly: **A red-haired woman surrounded by burning rubble.**
- [ ] Confirm the top result is `sintel_trailer-480p.mp4` near **23.25 s**, with thumbnail, score, and timestamp visible.
- [ ] Click the result and verify visible playback and sound on the recording machine. If browser decode fails, test **Open in local player**.
- [ ] Set browser zoom so cards and numbers are readable. Hide local paths, personal tabs, notifications, and unrelated windows.
- [ ] Record a short rehearsal and check text legibility, audio, playback, and the ending before the final take.
- [ ] Use [90-second](../demo-script-90s.md) narration; keep the [60-second](../demo-script-60s.md) backup ready.

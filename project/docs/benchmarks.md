# Benchmarks and evidence

The canonical benchmark and evidence summary is [`docs/evidence.md`](../../docs/evidence.md).

It separates:

- frozen retrieval quality on 24 positive queries across six film windows;
- persistent application performance measured on the recorded CPU host; and
- native Windows ARM64/QNN compatibility evidence whose hardware profiling remains incomplete.

No NPU speed, energy, HP deployment, or target application performance claim is supported.
